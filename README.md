- 💸 کیف پول — شارژ کارت‌به‌کارت با ارسال رسید و تأیید دستی ادمین، مبالغ پیشنهادی + مبلغ دلخواه، تاریخچه تراکنش‌ها

## 🗄 مرحله ۳ — ساخت KV Namespace ها از داشبورد

ربات از دو KV namespace استفاده می‌کنه: یکی برای داده‌های اصلی (BOT_KV) و
یکی برای سشن‌های موقت (BOT_SESSIONS).

1. برید به [dash.cloudflare.com](https://dash.cloudflare.com)
2. از منوی سمت چپ: Workers & Pages → تب KV
3. روی Create a namespace بزنید:
   - اسم: BOT_KV → Create
   - دوباره Create → اسم: BOT_SESSIONS → Create
4. آیدی هر دو namespace رو کپی کنید (تو لیست KV، ستون ID).

### 🔧 آپدیت کردن wrangler.toml روی GitHub

تو ریپو، فایل wrangler.toml رو باز کنید (یا Edit بزنید) و مقادیر id رو با آیدی‌های خودتون جایگزین کنید:

name = "vj-bot"
main = "src/index.js"
compatibility_date = "2024-11-01"

[vars]
BOT_NAME = "Vj_BOT"
BOT_USERNAME = "YourBotUsername"

kv_namespaces = [
  { binding = "BOT_KV", id = "<آیدی BOT_KV شما>" },
  { binding = "BOT_SESSIONS", id = "<آیدی BOT_SESSIONS شما>" }
]
Commit changes بزنید.

⚠️ آیدی‌های پیش‌فرض تو فایل، مال نمونهٔ دیگه‌ست. حتماً با آیدی‌های خودتون عوض کنید، وگرنه دیتای ربات شما با اون namespace قاطی می‌شه یا دیپلوی fail می‌کنه.

می‌تونید تو همون فایل، BOT_NAME و BOT_USERNAME رو هم به دلخواه عوض کنید
(فقط جنبه یادداشت داره، تو منطق ربات استفاده نمی‌شه).

🚀 مرحله ۴ — ساخت Worker و اتصال به گیت‌هاب (دیپلوی خودکار)

1. تو داشبورد → Workers & Pages → Create application → Create Worker
2. یه اسم بدید (مثلاً vj-bot) → Deploy (یه نسخه خالی deploy می‌شه، مهم نیست)
3. بعد از Deploy، برید به Worker → Settings → تب Build
4. بخش Connect to Git:
   · روی Connect بزنید
   · GitHub رو authorize کنید
   · ریپازیتوری خودتون رو انتخاب کنید
   · Branch: main
   · Build command: خالی بذارید
   · Deploy command: خالی بذارید (Cloudflare خودش Worker رو از wrangler.toml می‌خونه)
5. ذخیره کنید.

از این به بعد، هر push روی main خودکار دیپلوی می‌شه. 🎉

اگه Cloudflare ازتون خواست Worker رو دوباره deploy کنید، اولین بار دستی از داشبورد Deploy بزنید تا با کد جدید بالا بیاد.

آدرس Worker شما شبیه اینه:

https://vj-bot.<your-subdomain>.workers.dev
این آدرس رو نگه دارید — مرحله بعد بهش نیاز دارید.

🔐 مرحله ۵ — تنظیم Secret ها از داشبورد

سه مقدار محرمانه لازمه که نباید داخل wrangler.toml نوشته بشن؛ از داشبورد
تنظیم می‌شن و مستقیم رمزنگاری‌شده تو کلادفلر ذخیره می‌شن:

1. برید به Worker خودتون → Settings → تب Variables and Secrets
2. روی Add بزنید و این سه‌تا رو اضافه کنید (نوع: Secret):

Name Value
BOT_TOKEN توکنی که از BotFather گرفتید
OWNER_ID آیدی عددی تلگرام خودتون (نه یوزرنیم)
WEBHOOK_SECRET یه رشته تصادفی طولانی دلخواه (مثلاً ۴۸ کاراکتری)

3. بعد از افزودن هر کدوم، Save and Deploy بزنید تا Worker ری‌استارت بشه.

WEBHOOK_SECRET فقط برای این هست که مطمئن بشیم درخواست‌هایی که به Worker
می‌رسن واقعاً از تلگرام میان، نه از یه منبع دیگه.

🔗 مرحله ۶ — وصل کردن Webhook تلگرام (بدون ترمینال)

فقط کافیه این لینک رو تو مرورگر باز کنید (مقادیر رو جایگزین کنید):

https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://vj-bot.<your-subdomain>.workers.dev&secret_token=<WEBHOOK_SECRET>

https://api.telegram.org/bot123456789:AAExxx.../setWebhook?url=https://vj-bot.myaccount.workers.dev&secret_token=a1b2c3d4e5f6...
اگه پاسخ {"ok":true, "result":true, "description":"Webhook was set"} گرفتید، تمومه ✅
